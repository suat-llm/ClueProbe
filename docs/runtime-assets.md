# Runtime assets

Use a separate writable run directory containing `data/inference_jobs.jsonl` and relative video paths. The adapters record their own source/configuration/input hashes. Keep a separate run directory when changing any protocol or source; never merge incompatible runs.

Qwen8B Instruct additionally requires `data/qwen8b_identity_validation.json` and the original decoder-patch evidence expected by the adapter. VideoLLaMA3 requires `data/videollama3_main_handoff.json` plus the exact `adapters/runner_a6000_snapshot.py`; copy the tracked core to that location in the run directory. Checkpoint metadata and runtime receipts must refer to the locally supplied checkpoint. Do not manufacture passed receipts.

These files are external provenance inputs, not silently generated by installation. The repository is not an offline model/video distribution. The model-specific adapters retain their experimental version checks; install the corresponding environment instead of removing those checks.

The Qwen MAIN/TEXT source validates the canonical dataset size and model revision. A synthetic example is a schema illustration, not a substitute canonical manifest. The validated 8350 core and the newer 32B-specific deployment are different sources; their generation parameters and placement must not be conflated.
